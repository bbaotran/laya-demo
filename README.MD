# Laya Snake Demo


## Cài đặt (Windows)

```
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Chạy

```
python -m laya_snake --download   # tải mô hình (~0.65 GB), chỉ cần 1 lần
python -m laya_snake              # mở cửa sổ game
```
